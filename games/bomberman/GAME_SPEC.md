# 像素炸弹人 1.1.0

本文件是 bomberman 的规则权威来源。独立像素 Surface 只消费公开投影，平台契约见 [文档索引](../../docs/README.md)。

当前版本为一局三命。历史 `1.0.0` 的抢三胜规则、Core/Setup 与 golden 独立保留，详见 [历史规格](./GAME_SPEC_V1.md)；不能用当前规则重建旧记录。Surface `1.1.0` 按 exact gameVersion 解析两种投影并显示各自的规则与结算。

## 比赛与设置

自由混战，房主选择 2、3、4 人，默认 2 人。固定 classic-arena 地图与 classic 玩法；人数吻合、全员在线且分别准备后开局。设置变化清空准备，重新对局复用完整设置并要求全员重新确认。

一场平台 Match 只进行一局，每人开局 3 条命。准备 180 ticks，战斗最多 10800 ticks；统一扣命/淘汰后只剩一人即获胜，全员生命耗尽或限时仍多人存活则整场平局，不比较剩余生命。先判胜负，再检查限时。终局冻结战场，不自动重开；下一场沿用平台准备流程，重新生成地图并重置生命和道具。

玩家生命耗尽后仍可看当前对战。投降清零生命并永久退出本场，剩一名存活且未投降者直接获胜；无存活者为整场平局，已经耗尽生命的玩家不能因其他人投降而获胜。同 tick 投降先统一处理，再执行普通控制。主动离开、关闭及 60 秒断线超时沿用平台 abandoned 语义；断线宽限期间战斗继续。

## 地图与扩展

13×11 格，含外围硬墙，内部偶数行与偶数列的交点也是硬墙。四角各 3×3 安全区中的可行走格留空。按行优先枚举剩余格的横纵镜像组，每组以 70% 概率生成砖块；有砖块时以 30% 概率藏道具，容量、范围、速度等概率且同镜像组一致。抽样依次为砖块、是否含道具、道具类型；不做无界地图重试。

出生循环为左上、右上、右下、左下。2 人用第 0/2 个角，3 人用第 0/1/2 个角，4 人使用全角。开局通过 gameplay RNG 抽取循环偏移；配色编号跟随稳定参与顺序。安全区保证第一颗炸弹有可达的非爆炸格。

地图定义独立拥有尺寸、硬墙、安全格、砖块镜像组、出生循环与各人数布局；玩法定义拥有人数边界及时间、生命、无敌、道具和炸弹参数。参与者、生命和实体使用列表。当前地图支持 2–4 人，玩法最少 2 人；将来人数取地图、玩法与平台能力交集。现有平台上限为 8，超过该范围须另行扩展平台契约与性能验收。

## 操作与移动

60 Hz；每格 1200 整数单位，角色轴对齐碰撞体为 720×720。初始速度每 tick 80 单位，即 4 格/秒。四向输入，不斜移，人物可互穿。转弯时距离垂直格中心不超过 600 单位（半格）可自动居中：人物中点越过转角边界后即可向开放通道吸附，也支持经过通道中心后的回正。目标方向的相邻格被墙、砖块或不可穿行炸弹阻挡时不辅助转弯，避免提前转向反被拉回墙列。居中消耗正常移动预算，分段路径保持轴对齐，不能穿墙或穿弹。

MOVE 包含 up/right/down/left/none；有效移动租期为 30 ticks（接收 tick 计入），Surface 每 150ms 续租。无输入后最多 0.5 秒停止；停止、失焦、取消、断线、阶段/场次变化和销毁清理控制，恢复后重新操作。单次扣命保留有效移动控制，生命耗尽清理。键盘 WASD/方向键按最后仍保持的方向合成，空格按次放弹；手机为 20% 死区、主轴四向模拟摇杆与独立按次放弹按钮。

manifest 声明 events。同 tick 先处理全部投降，再保留每个玩家最后的 MOVE，完成移动后按规范事件顺序处理 PLACE_BOMB；因此放弹不会被移动覆盖。容量不足、同格已有炸弹、准备期或出局玩家的合法输入无效果，不排队补放。这些 accepted intent 仍遵循 canonical 日志语义；schema/身份/sequence/round 拒绝由 runtime 处理且不入日志。

## 炸弹与道具

| 参数         | 初始值      | 增强与上限                     |
| ------------ | ----------- | ------------------------------ |
| 同时在场炸弹 | 1           | 每个容量道具 +1，最多 5        |
| 十字爆炸距离 | 各方向 2 格 | 每个范围道具 +1，最多 8        |
| 移动速度     | 4 格/秒     | 每个速度道具 +0.5，最多 5      |
| 引信         | 150 ticks   | 放置后固定，不随玩家属性改变   |
| 火焰         | 30 ticks    | 重叠时延续至较晚结束时间       |
| 生命         | 3           | 每次受击 -1；本场不补充        |
| 受击无敌     | 120 ticks   | 存活受击者获得，期间不重复扣命 |

炸弹放在角色中心所在格，并记录放置时的范围。角色碰撞体与炸弹格重叠时具有一次穿出权限，完全离开该格后移除权限，所有炸弹随后阻挡进入。权限同样覆盖放置时重叠的其他玩家。无敌不提供穿墙/穿弹权限；出局玩家的炸弹继续生效至本场结束。

到期或接触存续火焰的炸弹引爆；按炸弹 ID 排序启动队列，十字方向为上、右、下、左。全部连锁使用同一份爆炸前硬墙、砖块和炸弹位置：硬墙阻断且不燃烧，砖块燃烧并阻断，另一炸弹燃烧、加入连锁并阻断。收集完整火焰与砖块销毁集合后再统一应用，不因遍历先后穿透砖块；同 tick 全灭不产生胜者。

火焰无敌我之分。移动路径接触已有火焰或移动后碰撞体接触新火焰时，每名非无敌玩家在同 tick 只扣一条命；伤害统一完成后再判胜负。还有生命则原地继续、保留道具并获得 120 ticks 无敌，可继续移动、放弹和拾取；受击 tick 为 t 时，在 t + 120 恢复受伤判定。零命才淘汰，不授予无敌。同一次爆炸、连锁或重叠火焰不能在无敌期间连续扣命。

砖块销毁后，道具等待该格全部火焰退去才显现；显现前不投影。公开道具被新的爆炸烧毁。存活玩家中心进入道具格即可拾取；同格按距中心最近、再按稳定参与顺序决定。升级只影响以后放置的炸弹，所有属性在下一场重置。

## 像素与声音反馈

火焰中心使用十字，横向/纵向传播格分别使用一字贴图。独立爆炸交叉时可显示交叉火焰；中心与两个轴分别记录结束 tick，旧方向熄灭后不能因另一方向延长而继续显示。

角色采用左右轴对称、各动画帧占位一致的居中俯视纹理，定位边框保持在服务器碰撞中心，编号始终清晰。无敌时保留定位边框与光圈，以 2.5 Hz 在完整/35% 不透明度之间闪烁；reduced-motion 使用常亮光圈，不闪烁。

放弹播放明显的正弦升降调泡泡声，拾取、受伤和淘汰也有独立反馈。爆炸起始音叠加一条共享持续轰鸣，按照公开火焰剩余时间续接，到最后一片火焰消失即停止；无新快照也有截止时间防止循环遗留。首次操作解锁音效，静音、失焦、断线、终局和销毁立即清理。加载、恢复与重连不补播旧事件；连锁共享持续声音，避免按火焰格重复叠加音量。

record-only；完整 Config、seed、参与者顺序、accepted events 与 finalTick 可重建本场及最终 Outcome。账户历史按 exact 版本校验后展示胜/负/平，不提供玩家回放。规则、地图、RNG 或输入解释变化须评估 gameVersion，表现变化独立评估 surfaceVersion。
