# 像素炸弹人 1.0.0

本文件是 bomberman 的规则权威来源。独立像素 Surface 只消费公开投影，平台契约见 [文档索引](../../docs/README.md)。

## 比赛与设置

自由混战，房主选择 2、3、4 人，默认 2 人。固定 classic-arena 地图与 classic 玩法；人数吻合、全员在线且分别准备后开局。设置变化清空准备，重新对局复用完整设置并要求全员重新确认。

一场平台 Match 含多个自动进行的小局，先赢 3 小局获胜。每小局准备 180 ticks，战斗最多 10800 ticks；统一淘汰后剩一人得 1 分，全灭或限时仍多人存活则无人得分。先判胜负，再检查限时。普通小局结算冻结战场 120 ticks，之后重新生成砖块、复活未投降者、重置道具并进入准备期；达到目标分立即结束整场。

玩家出局后仍可看当前小局。投降永久退出本场，剩一名未投降者直接整场获胜，全部投降为整场平局；同 tick 投降先统一处理，再执行普通控制。主动离开、关闭及 60 秒断线超时沿用平台 abandoned 语义；断线宽限期间战斗继续。

## 地图与扩展

13×11 格，含外围硬墙，内部偶数行与偶数列的交点也是硬墙。四角各 3×3 安全区中的可行走格留空。按行优先枚举剩余格的横纵镜像组，每组以 70% 概率生成砖块；有砖块时以 30% 概率藏道具，容量、范围、速度等概率且同镜像组一致。抽样依次为砖块、是否含道具、道具类型；不做无界地图重试。

出生循环为左上、右上、右下、左下。2 人用第 0/2 个角，3 人用第 0/1/2 个角，4 人使用全角。开局先通过 gameplay RNG 抽取循环偏移，每小局顺时针轮换一次；配色编号跟随稳定参与顺序。安全区保证第一颗炸弹有可达的非爆炸格。

地图定义独立拥有尺寸、硬墙、安全格、砖块镜像组、出生循环与各人数布局；玩法定义拥有人数边界及时间、道具、炸弹和计分参数。参与者、比分和实体使用列表。当前地图支持 2–4 人，玩法最少 2 人；将来人数取地图、玩法与平台能力交集。现有平台上限为 8，超过该范围须另行扩展平台契约与性能验收。

## 操作与移动

60 Hz；每格 1200 整数单位，角色轴对齐碰撞体为 720×720。初始速度每 tick 60 单位，即 3 格/秒。四向输入，不斜移，人物可互穿。转弯时距离垂直格中心不超过 240 单位可自动居中，居中消耗同 tick 的移动预算，分段路径保持轴对齐；超出容差时停止直到输入可行方向。

MOVE 包含 up/right/down/left/none；有效移动租期为 30 ticks（接收 tick 计入），Surface 每 150ms 续租。无输入后最多 0.5 秒停止；停止、失焦、取消、断线、换小局和销毁清理控制，恢复后重新操作。键盘 WASD/方向键按最后仍保持的方向合成，空格按次放弹；手机为 20% 死区、主轴四向模拟摇杆与独立按次放弹按钮。

manifest 声明 events。同 tick 先处理全部投降，再保留每个玩家最后的 MOVE，完成移动后按规范事件顺序处理 PLACE_BOMB；因此放弹不会被移动覆盖。容量不足、同格已有炸弹、准备期或出局玩家的合法输入无效果，不排队补放。这些 accepted intent 仍遵循 canonical 日志语义；schema/身份/sequence/round 拒绝由 runtime 处理且不入日志。

## 炸弹与道具

| 参数         | 初始值      | 增强与上限                   |
| ------------ | ----------- | ---------------------------- |
| 同时在场炸弹 | 1           | 每个容量道具 +1，最多 5      |
| 十字爆炸距离 | 各方向 2 格 | 每个范围道具 +1，最多 8      |
| 移动速度     | 3 格/秒     | 每个速度道具 +0.5，最多 5    |
| 引信         | 150 ticks   | 放置后固定，不随玩家属性改变 |
| 火焰         | 30 ticks    | 重叠时延续至较晚结束时间     |

炸弹放在角色中心所在格，并记录放置时的范围。角色碰撞体与炸弹格重叠时具有一次穿出权限，完全离开该格后移除权限，所有炸弹随后阻挡进入。权限同样覆盖放置时重叠的其他玩家。出局玩家的炸弹继续生效至小局结算。

到期或接触存续火焰的炸弹引爆；按炸弹 ID 排序启动队列，十字方向为上、右、下、左。全部连锁使用同一份爆炸前硬墙、砖块和炸弹位置：硬墙阻断且不燃烧，砖块燃烧并阻断，另一炸弹燃烧、加入连锁并阻断。收集完整火焰与砖块销毁集合后再统一应用，不因遍历先后穿透砖块；同 tick 全灭不产生胜者。

火焰无敌我之分。移动路径接触已有火焰或移动后碰撞体接触新火焰都会被淘汰。砖块销毁后，道具等待该格全部火焰退去才显现；显现前不投影。公开道具被新的爆炸烧毁。存活玩家中心进入道具格即可拾取；同格按距中心最近、再按稳定参与顺序决定。升级只影响以后放置的炸弹，所有属性在下一小局重置。
