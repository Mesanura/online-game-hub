# 坦克迷战 1.1.0

本文件是 tank-maze 游戏规则的权威来源。独立 SVG Surface 不运行权威物理。

## 对局与 Setup

2–8 人，默认 2 人；房主设置人数与目标分 5/10/15/20（默认 10）。已加入人数必须等于所选人数才能开始，超员需增加人数或离开；首版没有候补席或独立观战。按稳定席位分配八种互异颜色，玩家可选择未占用颜色。完整设置和颜色保留到下一场，但全部参与者须重新 ready。

每场平台 Match 含多个自动进行的小局。每小局重新生成地图并清空弹药、道具与输入，未投降玩家复活，准备 180 ticks。一次有效弹药命中即淘汰；只剩一辆时继续运行 240 ticks，幸存者得 1 分，期间全灭无人得分。全灭立即换图；多于一辆且战斗达到 7200 ticks 时无人得分换图，已触发的 240-tick 判定不受此限。首位达到目标分赢得整场。

投降立即永久淘汰本场，剩一个未投降玩家直接整场获胜，全部投降为整场平局。死亡玩家可观看当前小局，下小局复活。平台关闭、主动离开、60 秒重连超时沿用整场 abandoned 语义。

## 操作与确定性

W/S 或上下键前进/后退，A/D 或左右旋转，相反输入抵消；空格按次发射，不自动重复。触屏支持前进、后退、左右旋转与开火多指按钮。MOVE 保持 30 ticks，Surface 每 150ms 续租；失焦、触控取消释放，连接丢失无法送达释放时至多 0.5 秒归零。

60 Hz，坐标比例 1000，角度为 720 个半度单位，使用冻结整数方向表。前进每 tick 2000（与当前追踪导弹同速），后退 1083；转向每 5 tick 分配 48 个半度单位，左右均在 75 tick（1.25 秒）转完一圈。单 tick 使用 9 或 10 个整数半度步进，不累计浮点角度。所有状态累计值取整数；扫掠交点使用 IEEE-754 中间计算后量化，不依赖浏览器帧率或系统时间。

坦克渲染车体 38×30，碰撞体半径 19；圆形碰撞体使墙边旋转始终可行。接触组同步求解无惯性顶推：静止坦克可被推动，多个驱动者位移取平均，完全对向驱动抵消；任一成员遇墙，组停止。没有撞击伤害。弹药互穿、不抵消，所有攻击均可伤及发射者，死亡者弹药继续运行。同 tick 命中集合统一淘汰，避免先处理的死亡让另一颗弹失去目标。

输入为 strict MOVE(move, turn)、FIRE、RESIGN。manifest 声明 inputDelivery: events；同 tick 先按稳定参与席位顺序排列，同席位保留接收顺序。拒绝命令不写 canonical record；按次 FIRE 即使容量不足也不排队补发。

## 地图

每格 100 单位，宽 6–10 格、高 6–9 格独立随机，与人数无关；外框及内部墙厚 8，不可破坏。随机生成树保证基础连通，再开部分额外通道形成环；可封闭一个角格，仅在最大连通区域仍占至少 85% 时接受。算法有限遍历，无无界随机重试。

出生点和道具仅在最大连通区域格中心。出生点按最小间距最大化选择，并优先选择墙体遮挡的组合；若无法同时满足全部遮挡，保留分散且不重叠的合法点。随机初始朝向。地图每个小局生成一次。

## 弹药与道具

| 类型     | 数量、寿命和行为                                                                                                                                                                                      |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 普通弹   | 场上每人最多 5 颗，半径 3，速度 150/秒，780 ticks；遇墙反弹，命中后销毁，到期或命中立即释放容量。                                                                                                     |
| 激光     | 一次性长条弹，宽 4、显示长度最多 50，速度 1200/秒，60 ticks；墙和盾反弹，首个坦克命中销毁；持有时预览一秒墙体反弹路径，不预测动态盾。                                                                 |
| 追踪导弹 | 一次，速度 120/秒；前 180 ticks 直飞，之后追踪 600 ticks，总计 780；每 tick 找最近存活坦克（含自己），等距按 slotId 字符序；最大转向 90°/秒。遇墙不爆炸而反弹。追踪前灰黑烟，之后烟尾取当前目标颜色。 |
| 机枪     | 10 次额外按次射击，每颗普通弹尺寸和速度，780 ticks，不占普通容量。                                                                                                                                    |
| 护盾     | 半径 30，600 ticks，重复拾取刷新；所有从盾外进入的弹药反弹，已经位于盾内的弹药能伤到坦克。                                                                                                            |
| 霰弹枪   | 一次 20 枚，45° 总散布角，半径 2，速度 180/秒，180 ticks，可反弹。                                                                                                                                    |

一个特殊武器槽，加一个独立护盾。新武器替换未用完的武器；特殊武器耗尽立即恢复普通炮，所有特殊弹均不占普通弹 5 发名额。炮口距中心 29 单位，贴墙时不能隔墙生成弹药，而在墙前反射，允许盾内自伤。

`1.1.0` 的追踪导弹保留上述最近目标、速度、延迟、寿命和转向上限。目标可直达时直接追踪；被墙遮挡时通过格中心与通道中点组成的四邻接图寻路，按可见的路径点逐步绕墙。导航边和视线都按导弹半径检查墙体，不斜穿封闭拐角；目标移动、死亡或切换后重新选路。找不到通路时维持飞行及碰墙反弹，不穿墙、瞬转或延长寿命。

寻路使用由 `games/tank-maze` 独立持有的 `pathfinding@0.4.18` A*，避免引入另一套自研搜索引擎。固定非对角移动、Manhattan 启发式及库版本，不使用随机数；每 tick 的导航网格临时复用，搜索前复制，缓存和路径均不进入 State/View/Replay。更改库版本、邻居顺序或路径选取也必须评估新规则版本。

首次道具开战 300 ticks 后生成，之后随机间隔 300–480 ticks；最多 3 个，五种等概率，未拾取 1200 ticks 消失；避开墙、坦克及已有道具。进入最后坦克判定停止刷新。相同 tick 多人触碰，距离最近者获得，等距按 slotId 字符序。

## Surface、记录与版本

SVG 灰色网格迷宫、彩色矢量坦克、编号辅助识别。道具为中心固定的 40×40 SVG 图形。墙体缓存，动态节点复用；快照间仅作显示插值，重连/换图重置。击毁触发战场轻震 220ms，位移至多 2px；同批击毁合并、重复快照不重复触发，静态 HUD 不震动。音效由 Web Audio 合成，首次交互解锁，可静音，密集事件限制叠音；reduced-motion 关闭震动、烟尾与插值。准备阶段在战场中心显示 3、2、1 倒计时。

record-only，账户可读战绩，不提供玩家回放。Canonical header、Config、seed、accepted input events 能重建所有小局和最终 Outcome。改变物理、地图、输入解释、RNG、碰撞或计分须评估新 gameVersion；Surface 独立版本并保持 artifact digest 锁定。

`1.1.0` 使用缩小的地图、新转速与导弹绕墙寻路；`1.0.0` Core 和地图生成器冻结，保留宽 8–12 格、每 tick 5 个半度单位的历史转速及导弹直线追踪。两版共享兼容的公开 View/Setup，独立 golden fixture 验证 exact 重建。
