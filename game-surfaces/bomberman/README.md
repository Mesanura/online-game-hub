# 像素炸弹人 Surface

独立 TypeScript/Vite/Phaser 3.90 画面，只消费 Bridge V2 投影。规则由 [GAME_SPEC](../../games/bomberman/GAME_SPEC.md) 定义，公共构建与发布见 [Surface 规范](../../docs/GAME_SURFACE_SPEC.md)。

Setup 按 exact 规则版本展示初始属性、生命/胜场与掉落说明，以及房主可选人数、已确认设置、玩家配色和固定场地示意；示意砖块不是下一局权威布局。提交中防止重复，确认前保留服务器选择，过期或拒绝不自动重放。人数不符时给出中文提示，键盘焦点和移动端滚动保持可用。

Play 使用原创 16 像素调色板模板，32 像素逻辑格与最近邻缩放。整张地图等比适配，生命/胜场、限时、能力、散落道具、准备及结算均来自公开投影；跨小局、断线、死亡或转向不跨墙插值。受击后能力栏显示剩余属性，已有炸弹数可暂时高于降低后的容量。桌面显示键盘说明；窄屏与触屏提供模拟摇杆和放弹按钮，横屏在场地两侧，手机竖屏在场地下方，避让平台按钮。

方向键/WASD 使用最后仍按住的方向，空格初次按下才放弹。摇杆固定中心、20% 行程死区、主轴四向；等轴保持当前方向，无方向时优先横轴。摇杆有效方向优先，回中或释放后恢复仍按住的键盘方向。移动每 150ms 续租，方向变化立即发送。放弹触点独立，滑过按钮、长按或自动重复不额外放弹；多指可以同时移动与放弹。释放、取消、失焦、隐藏、断线、换小局和销毁丢弃旧触点，恢复后重新按下。

Web Audio 在用户交互后解锁，可静音，最多八个合成声部；只播放新事件，连接恢复和页面恢复不补播。减少动态效果关闭走路帧、道具浮动、炸弹闪烁、火焰动画与插值。

从 workspace root 使用该包的 dev、test、typecheck、artifact:lock 和 contract-test 脚本。公开 fixture 来自 Core/Setup 的 projectView，可在 Workbench 独立验证。record-only 仅有 Setup/Play 入口，没有 Replay 入口。完整验收按 [测试矩阵](../../docs/TESTING.md) 执行。
