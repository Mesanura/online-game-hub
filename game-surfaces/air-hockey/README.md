# 气垫球 Surface

独立的 Phaser Canvas 画面，支持 `air-hockey@1.0.0` 的 Setup / Play 与 Bridge V2。规则由 [GAME_SPEC](../../games/air-hockey/GAME_SPEC.md) 定义；开发、Workbench、摘要锁与发布步骤见 [Surface 规范](../../docs/GAME_SURFACE_SPEC.md)，检查范围见 [测试策略](../../docs/TESTING.md)。

Setup 展示服务器确认的 5／7／11 分设置，保留提交焦点，等待关联确认后恢复选择。房主固定为蓝色 P1，每局首发；玩家始终在画面下半场，P2 仅上下镜像。

Play 使用 600×1020 逻辑球场和四周 12px 留白，等比适配完整可视区域。鼠标移动控制，触屏在己方半场按下后单指拖动；跨过中线夹紧目标，移动合并至每秒最多 60 次，静止目标每 150ms 续租。触点结束、离开、失焦、页面隐藏、断线、换球和退出清理控制，重连需重新操作。

所有位置与比分来自权威投影。正常快照之间仅作显示插值，换球、阶段切换、重连和终局直接收敛。边框流光沿两侧开放边缘经过圆角，在球门开口停止，450ms 淡出；减少动态效果改为短暂静态高亮。

Web Audio 合成球拍、边缘与进球三类声音，首次点击或触控球场解锁，支持静音；按事件序号去重，首次加载和重连不补播。音频不可用不影响对局。投降复用平台确认，终局发送中文比分与胜负摘要；record-only 不提供 Replay 入口。
