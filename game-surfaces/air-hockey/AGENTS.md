# 气垫球 Surface 约束

- 只接收 Bridge V2 的公开投影，不能依赖 Core、客户端连接 SDK 或平台协议；不模拟碰撞或计分。
- P1 固定蓝色、P2 固定橙色。P2 仅上下镜像，球、球拍、球门及权威事件统一转换，左右保持不变。
- 鼠标在整个游戏页面直接跟随，移出球场仍发送夹紧目标；触屏只捕获己方半场的第一个触点。结束、取消、失焦、隐藏、断线、换球与退出清理旧目标；投降期间不发送 CONTROL。
- 声音与流光只消费新权威事件，加载和重连不补播；减少动态效果使用静态高亮。
- 发布前运行独立 test/typecheck/contract、摘要校验与浏览器检查。首次版本为 1.0.0，后续表现变更独立提升 surfaceVersion。
